Client for self-hosted SolidTime

Track your time,

Timezen is a native iOS time tracker for your own self-hosted SolidTime server. One-tap timer, rich history, dashboards, and dark mode — your data stays on your server.

Explore features View on GitHub

Everything you need to track time

Fast, focused, and made for people who host their own tools.

⏱️

One-tap timer

Start and stop with a tap. Add project, task, tags and billable — right from the home screen.

✏️

Edit anything

Adjust description, project, and start / end / duration on any entry. Resume or duplicate with a swipe.

📊

Dashboards

Day, week, month, half-month or custom ranges with per-project color charts and a project filter.

🌙

Dark & light

System, Light or Dark theme — switch anytime in Settings.

🏢

Multi-organization

Switch between the organizations you belong to on your SolidTime server.

🔒

Private by design

Your API token is stored in the iOS Keychain. Timezen talks only to your server — never to us.
